# 🧠 Impulsamente - Plataforma Web de Apoyo Académico y Emocional

> **Nota de Privacidad:** Este proyecto fue desarrollado como un prototipo web funcional para clientes reales (PYME). Por motivos de confidencialidad, algunos datos sensibles de la base de datos y configuraciones del cliente han sido omitidos o anonimizados.

## 📝 Descripción
Impulsamente es una plataforma web desarrollada para acompañar a estudiantes durante su proceso de tesis. El sistema integra herramientas de gestión de progreso académico con módulos de apoyo emocional, ofreciendo una experiencia integral a través de un dashboard interactivo, alertas de hitos y un chatbot de soporte.

## 🚀 Características Principales
* **Dashboard Interactivo:** Visualización del estado de avance de la tesis y métricas de estado emocional del usuario.
* **Sistema de Alertas:** Notificaciones automatizadas para el cumplimiento de hitos críticos del proyecto.
* **Chatbot de Apoyo:** Integración de un asistente virtual para brindar soporte inmediato al usuario.
* **Rendimiento y Seguridad:** Estrategias implementadas para respaldos de base de datos y optimización de carga.

## 🛠️ Tecnologías y Herramientas
* **Frontend:** React.js, TypeScript, Vite, Tailwind CSS.
* **Backend/BaaS:** Firebase.
* **Diseño UI/UX:** Prototipado en Figma.

## ⚙️ Metodología de Trabajo
El proyecto fue gestionado utilizando marcos de trabajo ágiles durante un ciclo de 12 semanas:
* **Framework:** Scrumban (Sprints de 2 semanas).
* **Gestión:** Tableros Kanban (Trello/Jira).
* **Ingeniería:** Levantamiento de historias de usuario y requerimientos funcionales/no funcionales.
